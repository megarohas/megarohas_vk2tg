# VK → TG

[English](README.md) | **Русский**

Крошечное Android-приложение, которое пересылает новые сообщения из VK
Мессенджера в чат Telegram. Оно читает уведомления VK
(NotificationListenerService) и отправляет каждое новое сообщение через
твоего Telegram-бота. Не нужны ни VK API, ни сервер, ни root: старый
планшет с залогиненным VK Мессенджером становится мостом.

```
💬 Иван Петров
в 7 в силе?

👥 Работа · Мария
отчёт в доке
```

## Возможности

- **Кто и что написал.** Отправитель и текст берутся из каждого сообщения
  внутри уведомления VK, для бесед добавляется название беседы.
- **Без дублей.** VK перевыкладывает одно уведомление на диалог со всей
  непрочитанной историей. У каждого сообщения есть отпечаток (чат,
  отправитель, текст, время), поэтому оно уходит ровно один раз, в том числе
  после перезапусков.
- **Ничего не теряется.** Сообщения копятся в сохраняемой очереди. Если
  Telegram или сеть недоступны, приложение повторяет попытки с паузой
  от 5 секунд до 5 минут. Сразу после возвращения сети и после
  переподключения слушателя оно пробует снова. Накопившиеся сообщения
  упаковываются в минимум сообщений Telegram.
- **Крошечное.** APK весит 29 КБ: чистая Java без зависимостей и без Gradle,
  только API платформы.
- **Приватное.** Токен бота хранится только в приватном хранилище приложения
  (бэкап выключен) и вычищается из всех сообщений об ошибках. В лог
  пишется только структура уведомлений, текст сообщений туда не попадает.

Приложение следит за `com.vk.im` (VK Мессенджер) и `com.vkontakte.android` (VK).

## Установка

**Из релизов.** Скачай `vk2tg.apk` из
[Releases](https://github.com/megarohas/megarohas_vk2tg/releases) и установи.
В Android 13+ приложениям, установленным из файла, доступ к уведомлениям
сначала закрыт. Перед выдачей доступа открой *О приложении → ⋮ → Разрешить
ограниченные настройки*.

**Из исходников** (Android SDK с build-tools 36 и platform 36, JDK 17):

```bash
make                                   # aapt2 → javac → d8 → zipalign → apksigner, пара секунд
export ADB_SERIAL=<ip-планшета>:<порт>   # беспроводная отладка
make install grant                     # установка + доступ к уведомлениям + без ограничений батареи
```

`make grant` делает через adb то же, что иначе пришлось бы делать в
настройках: выдаёт доступ к уведомлениям и снимает с приложения оптимизацию
батареи, чтобы сеть не отрубалась в Doze.

## Настройка

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. Напиши боту `/start` в личке. Можно и в группе: добавь туда бота и напиши
   `/start` там.
3. Открой **VK → TG**, вставь токен, нажми **Найти чат**, потом **Тест**.
   Должно прийти «✅ VK → TG на связи».

Или настрой всё с компьютера, не трогая планшет:

```bash
adb -s $ADB_SERIAL shell am broadcast -n com.megarohas.vk2tg/.AdbConfig --es token '<ТОКЕН>' --ez test true
```

Поддерживаемые параметры:

| Параметр | Что делает |
| --- | --- |
| `token` | Задаёт токен бота. |
| `chat` | Задаёт id чата. Пустое значение заново ищет чат. |
| `--ez test true` | Отправляет тестовое сообщение. |
| `--es say <текст>` | Отправляет ровно этот текст. |
| `--ez shell true` | Отладка: пересылать ещё и уведомления из `cmd notification post`. |

Любой вызов отвечает текущим статусом. Ресивер защищён разрешением
`android.permission.DUMP`. Им владеет только adb shell, поэтому никакое
другое приложение на устройстве не сможет подменить токен или перенаправить
сообщения.

## Замечания

- VK Мессенджер должен быть залогинен, а в его настройках уведомлений должен
  быть включён показ текста. Иначе переслать можно только «Новое сообщение».
- Пока приложение VK открыто на экране, VK не показывает уведомления. Оставь
  планшет на рабочем столе или на часах.
- После перезагрузки Android сам заново подключает слушатель, открывать
  приложение не нужно.

## Отладка

```bash
make status   # доступ, батарея, очередь, последняя ошибка
make log      # logcat: строка на каждое уведомление VK, отправки и повторы
```
